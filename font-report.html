Why weight 500 shifts by a fraction of a pixel

Clamping the axis to 400–600 re-quantizes Inter's interpolation deltas to whole font units. At weight 500, 48 glyphs land 1/2048 em (0.00049 em) off — 0.006px at 13px. The glyph edge antialiases one shade differently; nothing moves. Measured across 2,197 elements on 13 routes, the largest bounding-box change is 0.047px, and no element crosses 0.05px.

Deviations and their cost

  1. Latin-1 lives in the core, not the extended file

    Chrome does not kern across two @font-face rules — ÀV measures 56.48px as one face and 57.78px split at 40px. Routing accented letters behind unicode-range would change the spacing of any NFT name or collection title, so they travel with ASCII.

    +7,028 B vs an ASCII-only core accented text pixel-identical

  2. Hinting is kept

    Inter has zero glyph instructions, but deleting its 7-byte prep table changed DirectWrite rasterization: 14–74 px per page, max Δ 33. Keeping it returned that control to exactly 0. Features were dropped — dnom frac numr pnum ccmp mark mkmk are gone.

    +104 B per file identical rasterization

  3. • sits in the core

    It renders on /portfolio only. Behind unicode-range, that one glyph would pull 10 KB.

    1 glyph

  4. → is in neither range

    It is not in Inter's unicode-range today, so it draws from the system font. Including it would change its shape.

    0 px diff

  5. Weight 700 is not in the font

    font-bold, <strong> or a bare <th> would now render as 600 plus synthetic bold. Nothing in the app asks for 700 today.

    +564 B to widen to 400–700

  6. Latin Extended-A loses its kern pair against ASCII

    ĀV is 6.8px wider at 100px, ōw 1.8px. The old latin-ext file inherited those pairs from the latin file by accident; a separate file cannot. No page renders an Ext-A character.

    unreachable today

  7. Geist is gone

    The import matched no font-family. The package stays in package.json; it ships zero bytes.

    −76,420 B never built

  8. No internal rename

    Neither Inter nor Geist declares a Reserved Font Name, so the name table and license records are kept intact.

    OFL clean

Rerunning

python scripts/subset-fonts.py     # pip install fonttools brotli
npm run build

Rerun when the rendered characters change (new copy, new punctuation, content that can carry accents), when a weight outside 400–600 appears, or when @fontsource-variable/inter is upgraded. The script prints per-file bytes, char/glyph counts, surviving features and the 1-unit drift count, and fails loudly if a generated file's cmap does not match its declared unicode-range. Output is committed: public/fonts/*.woff2 and src/fonts/inter-subset.css.
